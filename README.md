# SkyAutoMusic

SkyAutoMusic 是面向 Windows 的《Sky 光·遇》自动演奏工具，提供现代化 PySide6 界面、悬浮控制、曲目预览、进度跳转和在线曲库更新。

## 下载

请从 [sky.xxlab.dev](https://sky.xxlab.dev) 下载：

- **Lite 精简版**：体积更小，内置《最后一吻》和《Call of Silence》，首次启动后可从 GitHub 更新完整曲库。
- **Full 完整版**：附带全部曲目，解压后即可离线使用。
- 国内网络可以在网站或应用内选择预设 GitHub 镜像线路。

下载安装器后按提示完成安装即可。默认安装到当前用户目录，程序和曲库更新使用普通用户权限；若游戏无法接收按键，可在应用设置中开启管理员模式。

## 功能

- 播放、扒曲、制谱、练习各有独立入口；播放和练习分别选曲
- “扒曲”集中提供在线搜索转换、MIDI / JSON / ZIP 导入、曲库更新和实时识曲
- 搜索、收藏和快速切换 JSON 曲谱
- 右键曲谱可删除到 Windows 回收站，同时清理收藏和本曲速度预设
- 主窗口与悬浮窗同步播放控制
- `F3` 全局开启或关闭悬浮窗
- 悬浮窗显示光遇 15 键琴谱、当前和弦和后续四组，支持手动、自动和 MIDI 跟谱翻页
- MIDI 键盘可直接接入光遇，切出游戏或断开设备时释放按键
- 本机音色预览，不向游戏发送按键
- 制谱和曲谱预览内置《光·遇》乐器采样音色，也可导入本地采样目录
- 演奏或预览中拖动进度并立即跳转
- 速度按原曲 BPM 倍率缩放，`1.00x` 即原速
- 随机延迟与错键效果
- `F7` 开始演奏，`F8` 停止演奏
- `Esc` 随时停止并释放全部按键
- 从 GitHub Release 在线更新曲库，支持 SHA-256 校验和国内镜像
- 已安装曲库后只下载版本间增量包，不重复下载完整曲库
- 支持从其他 HTTP/HTTPS 直链下载 JSON 或 ZIP 曲库
- 支持选择文件，或把 JSON / ZIP 直接拖入应用导入
- 支持导入 MIDI 自动转换为曲谱
- 接入 MIDI 键盘实时显示音名、力度和按键，支持本机钢琴试听与逐组跟弹
- 支持从 piastudy.com 搜索歌曲并一键转换到曲库
- 启动后后台检查软件版本，可在“关于”页手动检查并打开新版下载页面
- 曲库存在同名文件时自动追加序号保留，不再中断导入

## 悬浮琴谱与游戏内弹奏

在“播放”页选择曲谱，按 `F3` 打开悬浮窗，再点“琴谱”显示与光遇一致的 3×5 键位。亮键为当前音符组，下方显示后续四组；和弦用多个亮键表示。悬浮窗支持拖动和 100% / 85% / 70% 不透明度。

- `F5` / `F6`：上一组 / 下一组，也可点翻谱按钮。
- `F9`：按曲谱时间和当前速度自动翻谱。这个功能只翻谱，可看着提示自行在游戏里弹琴。
- `F4`：切换鼠标穿透，穿透后点击会传给游戏；再次按 `F4` 恢复操作悬浮窗。
- `F3`：显示 / 隐藏悬浮窗。`F8` / `Esc` 停止自动翻谱、演奏和 MIDI 接入。

自动演奏和本机预览会同步琴谱位置，拖动播放进度也会定位琴谱。手动翻谱与 MIDI 跟谱有独立位置。游戏请使用窗口化或无边框窗口模式；独占全屏可能遮住悬浮窗。若全局快捷键注册失败，程序会保留应用内快捷键并禁用鼠标穿透，避免无法解除。

## MIDI 键盘接入光遇

1. 将 MIDI 键盘接入电脑，打开光遇并进入乐器界面。
2. 在“设置 → MIDI 接入光遇”选择设备，点击“连接 MIDI”。悬浮窗的“MIDI 接入”按钮也可打开此设置。
3. 选择游戏窗口和音域（默认 C4–C6），点击“开始接入”，再切回光遇弹奏。
4. 如需跟谱，先在播放页选曲，打开悬浮琴谱并勾选“MIDI 跟谱”。弹对当前音符组后进入下一组；和弦需同时按住，重复音需松开再弹。

15 个 C 大调自然音映射到 `Y U I O P / H J K L ; / N M , . /`，黑键、音域外音符和延音踏板忽略。可以选择 C2–C4 至 C6–C8 的输入音域，游戏里的实际调性仍由游戏地点与背景音乐决定。

接入只在选中的光遇窗口位于前台时发送按键，切到其他窗口会立即释放已发送的键；切回后需松开琴键再弹。游戏关闭、设备变化、停止或退出程序也会释放按键。连接和开始接入都需要手动操作，不会在启动时自动开启。制谱、练习和游戏接入共用同一输入用途，连接其中一个会断开另两个。游戏不响应时，可在设置中开启管理员模式。

## MIDI 键盘练琴

1. 将 MIDI 键盘通过 USB 或 MIDI 接口连接电脑，确认 Windows 已识别设备。
2. 打开左侧“练习”页，选择输入设备并点击“连接键盘”；新接入设备可点击“刷新设备”。
3. 在练习页搜索并选择曲目，点击“开始练习”（F7）。蓝色键为当前目标，弹对后自动进入下一组；和弦需同时按住，重复音需松开再按。练习选曲与播放选曲互不影响。
4. 可切换练习音域（默认 C4–C6，中央 C 为 MIDI 60），或关闭“本机钢琴试听”使用键盘自身音色。`F8` / `Esc` 可停止练习并消音。

练习使用光遇曲谱的 15 个 C 大调自然音，不保留导入 MIDI 原谱中的黑键、原调和音符时值；适合熟悉键位与旋律，不评判节奏。键盘连接使用 Windows 自带 WinMM，无需额外 Python MIDI 库；设备需要系统可识别的 MIDI 驱动。连接被占用时请先关闭其他音乐软件。设备列表变化后需重新连接，避免连接到错误设备。

### 初学者模式

在“练习”页将模式切换为“初学者”，连接 MIDI 键盘即可练习，无需导入曲谱。内置认识 C、右手五指、左手五指、跟拍单音、短旋律五课，显示唱名与建议指法。

先听当前片段示范，再开始练习。每段最多 4 音，连续两轮无错后可点“下一段”；完成课程会记录日期，方便隔天复习。可关闭亮键提示，或打开 40–100 BPM 的节拍参考。节奏和实际指法不计分；分段大小和通关轮次是软件规则，不代表钢琴能力等级。

练习完成一轮后，页面会给出一行“教练建议”。它用本地掌握度记录和轻量表格 Q-learning 在“再练一轮、降速、保留提示、进入下一段、复习旧段”之间选择下一步；只保存到本机 `config.json`，不上传练习数据。建议用于安排练习，不等同于钢琴能力评定。

“入门指南”提供简短练法与研究链接。详细证据及适用范围见 [练习依据](docs/beginner-practice-research.md)。

## 从源码运行

需要 Windows、Python 3.11 或更高版本。

```powershell
python -m pip install -r requirements.txt
python play_music_qt.py
```

运行自动测试：`python -m pip install pytest`，再执行 `python -m pytest -q`。游戏输入测试使用模拟 MIDI 和窗口，实际接入还需在 Windows 上用实体键盘验证。

## 实时识曲

在“扒曲 → 实时识曲”选择光遇正在使用的电脑输出设备，点击“开始监听”。程序通过 Windows WASAPI 回环采集电脑声音，将听到的旋律与本地曲库比较；双击候选或点“打开选中曲谱”可进入播放页。只在手动开始后监听，不保存或上传音频，也不需要 API 密钥。

第一版为试验功能，适合单人、清楚的单音旋律。支持换调、八度变化、速度变化和少量漏音；需要至少 12 次相邻音高变化，连续重复音不累加。背景音乐、复杂和弦、混响和多人合奏可能影响准确度。结果的“音符吻合”表示旋律序列相似程度，不是正确识别的概率；未收录的歌曲无法识别。

首次开始会为本地 JSON 曲库建立旋律索引，大曲库可能需要几分钟；之后使用本机缓存，曲谱更改会在下次开始时更新索引。换一首歌可点“重新听一段”，停止演奏几秒后也会清空上一段结果。点击“停止”或按 `Esc` 结束监听。电脑声音采集依赖 Windows 的 PyAudioWPatch；源码用户需安装最新 `requirements.txt`。

## 构建

程序使用 Nuitka standalone 构建，再由 Inno Setup 封装成普通用户权限安装器；未使用 PyInstaller：

```powershell
python -m pip install nuitka ordered-set zstandard
python -m nuitka --standalone --enable-plugin=pyside6 --windows-console-mode=disable --include-package=keyboard --include-data-dir=assets=assets play_music_qt.py
```

准备 Lite 或 Full 文件目录后，可使用 `installer.iss` 生成安装器。默认安装到当前用户的 LocalAppData，因此应用内曲库更新不需要管理员权限。

## 曲谱格式

将 JSON 文件放入 `Sheet Music` 文件夹。乐谱需要包含 `songNotes` 数组；同一 `time` 下的多个 `key` 会同时按下。

“制谱”页使用光遇 15 音布局，提供“琴键模式”和“分离录制”两个录入模式。琴键模式下，电脑键盘或 MIDI 按住多个键后全部松开，会自动写入同一组音符。分离录制下，可以逐个点击或按键选音，松开后保持选中；再按同一个音可取消，按空格或点击“写入本组”才写入和弦并按所选节拍步进。点击“清空音高”可放弃当前组，切换模式会清空尚未写入的选择。

电脑键盘映射为 `Y U I O P / H J K L ; / N M , . /`。两种模式都支持 MIDI 键盘，按 C 大调音域映射录入，音域可切换为 C2–C4 到 C6–C8。切换到其他页面或关闭程序会断开制谱 MIDI 连接，已选的分离录制音高会保留，便于回来继续编辑。程序会记住录入模式。

## 光遇音色

应用内置 [Specy 的 Sky 采样目录](https://github.com/Specy/genshin-music/tree/main/public/assets/audio/sky) 中的光遇乐器音色，安装后可直接试听；采样授权文本见 `assets/sky_sounds/SPECY-MIT.txt`。也可选择本地乐器目录，要求包含连续编号采样；选择这些乐器目录的上一级目录时，可再选具体乐器。若内置文件缺失，音色选择器会显示修复下载按钮，完成后即可继续试听。

播放页可在演奏前选择带图标的乐器和具体演奏地点。地点选择会自动切换本机试听的调性；若当前背景音乐带来不同调性，可手动改“调性”，应用会按地点记住修正值。地点预设参考 [光遇全音调及地点攻略](https://www.bilibili.com/read/mobile?id=15735140)，部分地点需要等待背景音乐结束，详情见地点选择框的提示。实际游戏中的音高仍由游戏当前背景音乐决定，程序不会改变游戏调性。

部分乐器图标来自 [OpenMoji](https://openmoji.org/)，按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 使用；手碟、拇指琴、陶笛、排箫、琵琶、尤克里里和木琴图标由本项目绘制。

这些采样可能涉及《光·遇》权利人的授权范围，请按来源和权利人的条款使用；曲谱和音色是分别保存的，导出曲谱不会包含音色文件。

## Android 手机版

`mobile/android` 是可独立运行的 Android 版本。它在手机本地保存曲谱，使用系统无障碍服务的 `dispatchGesture` 点击屏幕，不需要电脑持续连接。第一次播放前，在系统设置中启用 **SkyAutoMusic 屏幕点击**，然后按游戏横屏时的屏幕宽高百分比校准 15 个坐标。点击播放后有 3 秒时间切回游戏。

每次构建 Android APK 时，Gradle 会先把桌面 `Sheet Music` 中的曲谱复制到手机离线曲库，移除桌面已删除的曲谱并排除备份文件。桌面曲库更新后重新构建并发布 APK，手机安装新版后即可使用更新曲库：

```powershell
tools\build_mobile.ps1
adb install -r mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

发布版使用 `tools\build_mobile.ps1 -Release`。脚本调用 Gradle 的 `syncDesktopScores` 任务，每次构建都会从当前桌面曲库重新生成 Android assets；不需要手动复制曲谱。

手机端的“从电脑同步”是可选的：在桌面端设置中启动“手机同步”，手机和电脑连接同一局域网后输入地址与令牌。同步的曲谱会写入手机，之后可以关闭电脑和 Wi-Fi 继续播放。更新 APK 时会再次打包当前桌面曲库；使用局域网同步的用户无需重装 APK 即可拉取电脑当前曲谱。
