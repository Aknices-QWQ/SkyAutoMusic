核心功能

从选曲到演奏，只保留必要步骤

  1. 01

    快速找到曲目

    主窗口和悬浮窗都支持输入歌名；没有结果时可直接向维护者提交扒谱请求。

  2. 02

    按原曲 BPM 变速

    1.00x 始终代表原速，其余倍率以乐谱原始速度为基准加速或减速。

  3. 03

    紧凑悬浮控制

    按 F3 随时呼出；切歌、预览、开始、停止和进度跳转都在一个小窗口内。

  4. 04

    增量曲库更新

    只下载发生变化的曲谱，国内网络可选择预设 GitHub 镜像线路。
